# Imagens do KAENA Guaratuba

Esta pasta contém todas as imagens utilizadas na Landing Page.

## Como inserir as imagens do Drive

1. Acesse o Drive com os materiais do KAENA
2. Baixe as imagens/renders em alta resolução
3. Converta para WebP (recomendado) ou JPG
4. Salve nesta pasta com os nomes abaixo

## Dicas de otimização

- Use **WebP** sempre que possível (40% menor que JPG)
- Dimensione as imagens corretamente antes de subir
- Imagens do hero: máx. 400-600 KB
- Imagens da galeria: máx. 200-300 KB cada
- Use `imagemin`, `squoosh.app` ou `TinyPNG` para comprimir

---

## Imagens que a Landing Page tenta carregar automaticamente

Se uma imagem não for encontrada, a seção mostra um **placeholder elegante** com
o nome do que deveria estar ali. Não há quebra visual — apenas substitua o arquivo
pelo nome correto quando estiver disponível.
